# nicro

Панель для собственного VPN: протоколы, устойчивые к блокировкам (VLESS REALITY с маскировкой под ваш сайт, XHTTP),
клиенты и тарифы, точные устройства, кластер серверов, Telegram-бот с оплатой и поддержкой. Веб-панель
устанавливается на телефон как приложение (PWA). Интерфейс и клиентская часть (бот, страницы) — на русском и английском.

> Self-hosted VPN panel (Xray-core VLESS REALITY / XHTTP) with clients, plans, payments, Telegram bot, support desk,
> multi-server cluster and Russian-IP entry points. Russian / English.

## Установка — три команды

### 1. Главный сервер с веб-панелью

Чистый VPS вне России: **Ubuntu 22.04 / 24.04 или Debian 12 / 13**, x86_64 или arm64, от 1 ГБ памяти
(512 МБ — минимум), свободные порты 80, 443, 2053, 2083, 2087, 8443.

```bash
curl -fsSL https://raw.githubusercontent.com/nikels522-cyber/nicro/main/install.sh | sudo bash
```

В конце установщик покажет **адрес панели, логин и пароль** (пароль — один раз, сохраните) и готовую команду
для точки входа. Панель живёт по секретному адресу `https://<ip>.sslip.io:2053/<случайный путь>/` — его не
публикуйте.

Свой домен для панели можно задать сразу: `curl … | sudo DOMAIN=panel.example.com bash` (A-запись → IP сервера)
или позже в панели. Повторный запуск той же команды **обновляет** панель, сохраняя клиентов, ключи и настройки.

После установки:

1. Войдите, смените пароль, включите 2FA — *Безопасность → Мой аккаунт*.
2. Создайте клиента — *Клиенты → Создать*. В карточке клиента первая кнопка — «Поделиться»: одна ссылка
   на любое устройство (страница с кнопками установки приложения и добавления подписки).
3. Рекомендуется: свой домен для маскировки — A-запись (например `nl.example.com`) → IP сервера, затем
   *Настройки → «Свой домен для маскировки»*. Ключи «🛡 свой домен» проходят там, где режут чужую маскировку.
4. Telegram-бот — @BotFather → `/newbot` → токен в *Дополнения → Telegram-бот*.
5. Приложение на телефон — кнопка *«📱 Приложение на телефон»* в меню: QR-код и инструкция для Android и iPhone.
   Администратору, указавшему свой Telegram ID (*Безопасность → Мой аккаунт*), бот по `/panel` присылает панель —
   она открывается прямо в Telegram, а кнопка меню бота «nicro» всегда ведёт в панель.

### 2. Точка входа (российский IP)

Raspberry Pi, мини-ПК или VPS в России — пересылает подключения на главный сервер. Нужна, если мобильные
операторы режут зарубежные адреса. Шифрование сквозное: на точке входа нет ни ключей, ни данных клиентов.
Debian / Ubuntu / Raspberry Pi OS.

Готовая команда с вашими данными — в панели: *Серверы → «Точка входа»* (и в конце установки главного сервера):

```bash
curl -fsSL https://raw.githubusercontent.com/nikels522-cyber/nicro/main/install-relay.sh \
  | sudo bash -s -- --master https://<ip-панели>.sslip.io:2053 --token <токен точек входа>
```

| Параметр | Что вводить |
|---|---|
| `--master` | адрес панели **без** секретного пути (как «Базовый URL подписок» в настройках) |
| `--token` | токен точек входа — уже подставлен в команде из панели |
| `--name` | как точка называется у клиентов, например `RU-1` (спросит, если не указать) |
| `--ssh-allow` | необязательно: пускать по SSH только с этого IP (скрипт попросит подтвердить вход) |
| `--ssh-user` | чьими SSH-ключами управлять из панели (по умолчанию тот, кто запустил `sudo`) |

После установки точка **сама появится в панели** (*Серверы → Точки входа*), её ключи «через RU-1» добавятся
в подписки всех клиентов, владельцу придёт сообщение в Telegram. Дальше:

- *Обзор → Проверка из РФ → «Проверить»* — ключи через точку должны быть зелёными;
- желательно свой домен: A-запись `ru.example.com` → IP точки, затем *Серверы → точка → «изменить»*;
- если машина дома за роутером — пробросьте TCP 80, 443, 2083, 2087, 8443, 9443, 9444 и UDP 443, 8388;
  порт 9101 должен быть доступен главному серверу;
- IP точки сменился (домашний интернет) — панель обновит ключи сама; для домена на reg.ru укажите доступ к API в
  *Настройки → Свой домен и DNS*.

### 3. Узел-выход (ещё одна страна)

Чистый VPS (Ubuntu / Debian), свободные порты 80, 443, 8443. В панели: *Серверы → «Узел-выход»* → название
(например «Германия») → одноразовая команда (действует 1 час):

```bash
curl -fsSL https://raw.githubusercontent.com/nikels522-cyber/nicro/main/install-node.sh \
  | sudo bash -s -- --master https://<ip-панели>.sslip.io:2053 --token nkl_join_...
```

| Параметр | Что вводить |
|---|---|
| `--master` | адрес панели без секретного пути |
| `--token` | одноразовый токен — уже в команде из панели |
| `--domain` | необязательно: свой домен узла (A-запись → IP узла), иначе `<ip>.sslip.io` |

Узел ставит Xray и сайт-маскировку с сертификатом, подключается к кластеру и через несколько секунд получает
всех клиентов. Его ключи появляются в подписках сами; трафик, лимиты и устройства общие для кластера.
Если главный сервер недоступен, узел продолжает работать с последней конфигурацией.

## Возможности

- **Протоколы**: VLESS REALITY Vision и XHTTP (маскировка под чужой сайт и под свой домен с настоящим
  сертификатом), Hysteria2 и Shadowsocks 2022 (включаются отдельно), MTProto-прокси для Telegram, L2TP/IPsec.
- **Клиенты**: лимиты трафика и срока, «1 устройство», точный учёт устройств (по ID устройства из Happ / v2RayTun,
  иначе по адресам), семьи, скорость, импорт/экспорт CSV, массовые действия.
- **Умная ссылка** `/c/<код>`: в браузере — страница под устройство клиента (Android, iPhone, Windows, Mac)
  с кнопками установки и импорта, оплатой и промокодом; в приложении — обычная подписка.
- **Кластер**: точки входа с российским IP (HAProxy + PROXY protocol, реальные IP клиентов), узлы-выходы,
  автопереключение (упавший сервер уходит из подписок), проверка ключей из РФ, страница статуса.
- **Продажи**: тарифы, онлайн-оплата (ЮKassa, CryptoBot, NOWPayments, Telegram Stars, перевод по реквизитам —
  осталось вписать ключи), промокоды, реферальная программа, пробный период.
- **Telegram-бот**: клиент присылает свою ссылку или ключ — бот узнаёт аккаунт; напоминания о сроке и трафике,
  покупка, поддержка; команды для администраторов.
- **Поддержка**: обращения из бота в панели или в Telegram сотрудникам (основной бот или отдельный бот
  поддержки), статусы, ответственный, шаблоны ответов, роль «Поддержка».
- **Сеть**: российские сайты напрямую (профиль маршрутизации Happ), WARP для ChatGPT / Gemini,
  блокировка рекламы, ограничение скорости (tc + метки соединений).
- **Надёжность**: бэкапы в Telegram и облака (Яндекс Диск, Облако Mail.ru, Google Drive, Dropbox, OneDrive,
  S3, WebDAV, SFTP), восстановление, оповещения, еженедельный отчёт.
- **Безопасность**: секретный путь панели, файрвол по IP, 2FA, роли (владелец, оператор, поддержка,
  наблюдатель), журнал действий, управление SSH на всех серверах кластера из панели.

## Панель на телефоне

В меню панели — *«📱 Приложение nicro»*: QR-код для телефона. Открыв его, телефон сразу предлагает установку,
в любом браузере:

- **Android** — приложение nicro (`nicro.apk`, 30 КБ, собирается GitHub Actions из `android/`). Кнопка
  «Скачать приложение» копирует адрес панели, приложение при первом запуске подставляет его само.
  Подпись APK открытая (`android/nicro-release.keystore`) — для своей сборки создайте свой ключ.
- **iPhone / iPad** — профиль с иконкой на экране «Домой» (`nicro.mobileconfig`, Web Clip на весь экран):
  «Разрешить» → Настройки → «Профиль загружен» → «Установить».
- Браузеры, умеющие ставить сайты как приложения (Chrome, Edge, Яндекс), показывают ещё и свою кнопку «Установить».


## Обслуживание

| Что | Как |
|---|---|
| Обновить панель | команда установки главного сервера ещё раз |
| Сбросить пароль | `cd /opt/vpnpanel && set -a && . /etc/vpnpanel.env && set +a && venv/bin/python -m app.cli admin admin <пароль>` |
| Заблокировали себя файрволом | `… venv/bin/python -m app.cli firewall off && systemctl restart vpnpanel` |
| Адрес панели и команда точки входа | `… venv/bin/python -m app.cli info` |
| Токен для узла из консоли | `… venv/bin/python -m app.cli node-token Германия` |
| Переезд на новый сервер | установите панель, затем *Безопасность → Бэкапы → Восстановить* (или `app.cli restore файл.tar.gz --with-env`) |
| Журналы | `journalctl -u vpnpanel -f`, `journalctl -u xray -f` |

## Разработка

```
backend/   FastAPI + SQLAlchemy (SQLite), ядра Xray / Hysteria / mtg, бот, оплата, кластер
frontend/  React 19 + Vite + Tailwind 4 (PWA)
deploy/    установщик панели, настройка точки входа и её агент
install*.sh  установка одной командой (скачивают код с GitHub)
```

- Фронтенд: `cd frontend && npm ci && npx vite build` (GitHub Actions собирает его на каждый коммит в релиз
  `frontend-main`, установщик берёт готовую сборку).
- Переводы панели: строки пишутся по-русски внутри `tr("…")`; `node frontend/scripts/i18n-wrap.mjs` оборачивает
  новые строки и обновляет `frontend/src/locales/keys.json`, перевод — в `locales/en.json`.
- Переводы для клиентов (бот, страницы): `backend/scripts/make_locales.py` — проверяет, что у каждой фразы есть
  английский перевод, и пишет `backend/app/locales/en.json`.
